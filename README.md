# senninappbuilder

ブロックをならべて、アプリのコードを作れるツールです。

## 使いかた

1. `npm install` を実行します。
2. `npm run dev` を実行して、ブラウザで表示されたページをひらきます。
3. 上のボタンで「チャット」「掲示板」「情報をとってくる」「数当てゲーム」からえらびます。
4. 「どうさ」の欄で、ブロックをならべかえたり、中身（はこの名前、URLなど）を変えたりします。
5. 「📦 ZIPでダウンロード」を押すと、フロントエンド（React）とバックエンド（Node.js）のコードが入ったZIPがダウンロードされます。

作りかけの作品はブラウザのlocalStorageに自動で保存されます。

## ブロック

| ブロック | 色 | はたらき |
| --- | --- | --- |
| データを追加する | オレンジ | おくられた内容を、はこに入れる |
| データを全部取り出す | オレンジ | はこの中のデータを全部わたす |
| ページを読む | 青 | インターネットのページを読みこむ |
| 文字をさがして取り出す | 青 | 正規表現に合う部分を取り出す |
| かえす | むらさき | ここまでの結果をアプリにわたす |

## 出力されるコードについて

- バックエンド: Node.js + Express + TypeScript。データは `data.json` に保存されます。
- フロントエンド: React + TypeScript + Vite。
- 数当てゲームは、サーバーを使わず画面だけで動きます。

## 今の制限

- ブロックはドラッグ&ドロップではなく、クリックで追加します。
- ブロックから作れるのは「サーバーのどうさ」の部分です。画面の見た目は、アプリの種類ごとのテンプレートで決まります。
- 生成されるコードは、Node.js 18以上で動作を確認する想定です。
